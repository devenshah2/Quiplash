# GIF shelf

Animated Noto Emoji © Google LLC, used under the [Creative Commons Attribution 4.0 International license](https://creativecommons.org/licenses/by/4.0/).

The [original collection](https://googlefonts.github.io/noto-emoji-files/?view=docs) is distributed by Google Fonts. Each GIF in this folder is a resized and frame-rate-reduced version of the animation with that Unicode code point. The reaction titles and search terms are specific to this game.

An original can be located by replacing CODE with the GIF filename without its extension in `https://fonts.gstatic.com/s/e/notoemoji/latest/CODE/512.gif`.

The in-browser GIF resizer uses [omggif 1.0.10](https://github.com/deanm/omggif) by Dean McNamee, used under the MIT license reproduced in omggif.js.
